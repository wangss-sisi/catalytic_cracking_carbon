# 350万吨/年催化裂化装置碳排放统计分析系统

## 系统简介

本系统用于统计和分析350万吨/年催化裂化装置的碳排放数据，包括计划执行情况录入、烟气成绩录入、碳排放计算、数据展示和趋势分析等功能。

## 运行环境

系统基于Python和Flask框架开发，使用SQLite数据库存储数据。

## 快速开始

### 方法一：使用可执行文件（推荐）

1. **下载系统**：
   - 从提供的压缩包中解压系统文件到任意目录

2. **运行系统**：
   - 双击运行 `启动系统.bat` 文件
   - 系统会在后台启动Flask服务器

3. **访问系统**：
   - 打开浏览器，访问 `http://127.0.0.1:5002`
   - 使用默认用户名 `admin` 和密码 `admin` 登录

### 方法二：使用Python运行

1. **安装依赖**：
   - 确保已安装Python 3.7或更高版本
   - 运行 `pip install -r requirements.txt` 安装依赖项

2. **启动系统**：
   - 运行 `python app.py` 启动Flask服务器

3. **访问系统**：
   - 打开浏览器，访问 `http://127.0.0.1:5002`
   - 使用默认用户名 `admin` 和密码 `admin` 登录

## 系统功能

1. **计划执行情况录入**：录入装置的运行数据，包括烧焦量、加工量等
2. **烟气成绩录入**：录入烟气成分数据，包括O2、CO2等
3. **计算碳排放**：根据计划执行情况和烟气成绩计算碳排放数据
4. **查看碳排放数据**：查看详细的碳排放活动水平数据表
5. **趋势分析和预测**：分析碳排放数据的变化趋势并进行预测

## 数据管理

- **数据存储**：系统使用SQLite数据库存储数据，数据库文件为 `carbon_emission.db`
- **数据备份**：建议定期备份 `carbon_emission.db` 文件
- **数据导入导出**：系统支持Excel格式的数据导入导出

## 技术支持

如果遇到问题，请检查以下事项：

1. 确保系统文件完整，特别是 `templates` 目录中的模板文件
2. 确保端口 5002 未被其他程序占用
3. 检查系统日志，查看是否有错误信息

## 注意事项

- 系统默认使用端口 5002，如果需要修改端口，请编辑 `app.py` 文件
- 首次运行时，系统会自动创建数据库和默认用户
- 建议定期备份数据库文件，以防数据丢失
